Geocodificación Automática para tu Google Sheets

¿Quieres que tu Google Sheets convierta automáticamente las direcciones de La Florida en coordenadas de Latitud y Longitud? Puedes pegar este script gratuito en tu Google Sheets en 1 minuto:

1

Abre el editor de scripts en Google Sheets

En tu planilla haz clic en el menú: Extensiones → Apps Script.

2

Pega el siguiente código y presiona Guardar (💾):

/**
 * Geocodificador Automático para Bomberos La Florida
 * Agrega Coordenadas (Latitud y Longitud) a cada dirección de La Florida
 */
function GEOCODIFICAR_LA_FLORIDA(direccion) {
  if (!direccion) return "";
  try {
    var query = direccion + ", La Florida, Región Metropolitana, Chile";
    var response = Maps.newGeocoder().geocode(query);
    if (response.status === 'OK' && response.results.length > 0) {
      var loc = response.results[0].geometry.location;
      return loc.lat + ", " + loc.lng;
    }
    return "No encontrado";
  } catch(e) {
    return "Error";
  }
}

💡 Cómo usarlo en la celda: En una nueva columna de tu Google Sheet escribe:
=GEOCODIFICAR_LA_FLORIDA(C2) (donde C2 es la celda de la dirección). ¡Google Sheets calculará las coordenadas exactas al instante!
